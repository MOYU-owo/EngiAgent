# EngiAgent Demo Knowledge

这是一份用于演示工具调用的本地知识文件，不是真实工程规范，不能用于实际设计、验算或施工决策。

## Demo 安全系数

本演示约定的安全系数为 **1.5**。

该数值只用于验证 Agent 能否从本地资料中检索并引用信息，不代表任何国家、行业或项目规范要求。

## 单位约定

Demo 默认采用 SI 单位制。长度优先使用米（m），力优先使用千牛（kN）。进行真实计算前必须再次确认输入量纲和单位一致性。

## 使用边界

Demo 知识不得替代正式规范、注册工程师判断、试验结果或经过验证的工程计算。信息不足时，Agent 应明确说明限制，而不是补造参数。
