# 中国规范 RC 梁任务与工具计算说明

版本：cn-rc-2024-v1，2026-10-25。本文先于计算函数建立，实施与验证结果另记。

## 任务边界

普通房屋、设计工作年限50年、安全等级二级、重要性系数1.0、环境类别一类、非预应力、非抗震专项；单跨简支矩形梁，全跨均布恒载和单一活载，单层HRB400/HRB500受拉钢筋；混凝土C25—C50。仅承受竖向不利重力作用，不处理疲劳、扭转、轴力、集中荷载、深梁、开洞、吊车及施工阶段。

跨度输入为支座中心线间计算跨度，支座宽度另外提供。荷载为线荷载标准值。活载用途对应的组合值、频遇值、准永久值系数由用户提供并确认，不根据“住宅”等名称猜测。钢筋公称面积按πd²/4计算。

环境、寿命、安全等级和材料等级均展示确认。直径、根数、箍筋间距、上下部及侧面构造筋、端部锚固长度均有明确输入或方案记录。工程边界之外的要求必须另外审查，本程序不签发全面工程合规证明。

ξb=β1/(1+fy/(Es εcu))。本模型不计受压钢筋对承载和刚度的有利贡献，上部钢筋作为构造输入；不通过减小受压区高度伪造超筋截面的承载力。

### 裂缝与长期刚度采用值

非预应力RC梁采用准永久组合 Mq。σs=Mq/(0.87h0As)，Ate=0.5bh；ψ=clamp(1.1−0.65ftk/(ρteσs),0.2,1.0)。零荷载返回零裂缝和零挠度，避免除零。若σs超过fy，返回模型不适用。

wmax=1.9ψ(σs/Es)(1.9cs+0.08deq/ρte)。同直径带肋筋deq=d，cs=clamp(c+dsv,20,65)。仅裂缝工具将ρte下限取0.01；刚度工具采用原始As/Ate。

Bs=EsAs h0²/[1.15ψ+0.2+6(Es/Ec)ρ]，其中ρ=As/(bh0)。不计受压筋有利作用，θ=2、B=Bs/2；f=5qq L⁴/(384B)。当前普通楼屋盖无特别挠度要求，表3.4.3的限值分母为L<7m取200、7m≤L≤9m取250、L>9m取300，与用户要求取较严格者；对需更严控制的使用功能必须输入相应限值。

### 适用构造的实现约定

- 最小受拉面积=max(0.002,0.45ft/fy)bh，来源GB55008表4.4.6。
- 普通50年一类环境梁箍筋保护层≥20mm，C25提高5mm；另外核查箍筋及纵筋各自的保护层不小于相应直径。
- 下部净距≥max(25,d,4Dagg/3)，上部净距≥max(30,1.5dtop)。骨料净距为附加可施工性检查，不能混写成9.2.1全部原文。
- 架立筋跨度<4m、4—6m、>6m的建议直径分别8、10、12mm；本项目把“不宜”值列入接受检查，保留条文效力说明。若实际部分约束，不属于此理想铰支模型。
- hw=h0≥450mm时，每侧独立腰筋面积≥0.001bhw、间距按建议值≤200mm；上下纵筋及架立筋不计入腰筋面积。
- 端部采用一般充分受拉直锚的保守方案，la=max(0.14fy/ft·d·ζa,200)，d>25时ζa=1.1；不采用有利折减、无涂层、非施工易扰动情形。此长度不声称是9.2.2全部简支端部的唯一必要长度。直锚须容纳于支座；保护层≤5d时锚固区横向钢筋间距≤min(5d,100)。输入锚固区间距与跨内间距分别核查。
- 剪力大于0.7ftbh0时检查0.24ft/fyv最小配箍率，低剪力不机械套用该强制下限。最大箍筋间距按9.2.9高度和剪力分档；h≤150mm仍配置箍筋及采用第一档间距是本项目保守策略。h>800mm箍径采用建议值≥8mm。
- 全跨等配筋，无搭接、截断；首箍距支座边缘≤50mm、封闭箍、腰筋拉结及施工节点需要详图落实，报告明确这些未由输入几何完整验证的事项。

承载力不足、单筋适用性失效与工具异常分别记录；“请求项目通过”仅指上述计算与声明条件，不代表所有工程设计内容已经审核。

## 工作流与失败处理

完整设计：参数校验与确认 → 工程DAG → 截面/材料/荷载/内力 → 受弯与受剪配筋 → 根据实际方案独立验算全部目标 → 报告，或有限改设。

已有梁：保留用户截面及实配钢筋，直接进入Evaluation。仅抗弯且已给设计弯矩时，只执行材料、实际几何与抗弯检查。局部验算不输出全面通过结论。

修改：创建修订、重新确认；使用实际字段输入、上游输出、规范配置及工具版本判断复用。缺项和上游异常阻断依赖节点；其他独立检查继续。数值检查不通过属于工程结论，不是工具异常。

有限改设：仅新设计且用户开启；外层LangGraph循环，单轮内部保持DAG。未给尺寸可在显式最大尺寸内试选，已给尺寸视为固定；纵筋只在确认直径和单层根数范围内调整。无解或达到次数限制停止，保留每轮记录。

## 验收要求

1. 独立基准算例覆盖荷载、自重、有效高度、Mu、V、实配容量、裂缝与长期挠度。
2. 完整设计、完整验算、仅抗弯、缺项、非法值及不支持工况均有测试。
3. 局部重算与全量重算数值一致，自重已含和另计两种依赖均验证。
4. 改设成功与无解、模型格式错误、工具异常、API失败均不产生虚假通过。
5. 教学模式和Demo回归；真实模型验证单独记录，不以离线替身冒充。
