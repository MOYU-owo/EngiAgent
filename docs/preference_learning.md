# 最小工程师偏好学习驱动设计

实现于 `feature/preference-optimization`。不新增Agent、数据库或独立实验系统，不修改CN公式、DAG及Evaluation。默认关闭引导。

## 使用

1. 在设计工作台加载「截面与配筋联合设计」，确认并运行。
2. 页面底部「设计偏好」直接展示两份合格方案的截面、配筋、受拉纵筋面积和验算利用率。点击「更喜欢左侧」或「更喜欢右侧」，选择立即保存；可用「换一组方案」继续比较，也可在下拉框指定方案。仅允许比较三项偏好特征不同的合格方案。
3. 点击「本次设计使用我的偏好」→回到上方「确认参数」→「运行任务」。不再需要勾选开关、再保存一次设置。需要关闭时，点击「本次设计不使用偏好」并重新确认。
4. 「查看已记住的偏好」默认收起，包含重视程度和最近10条评价，完整历史保存在本地文件中。
5. 可选演示：展开「模拟体验与效果对比」，切换「模拟选择（仅演示）」，点击「自动体验20次选择」。这会重复比较当前候选，不会新增20个设计任务。模拟与真实记录分别保存，不能互用。切回「我的选择」即可恢复真实评价。
6. 在同一折叠区点击「比较使用偏好前后」。原工具执行两次独立、空缓存、相同输入和预算的搜索，展示合格方案数量与分布；可下载完整对比记录。对照不替换当前设计结果，不调用DeepSeek。

保存评价与启动设计是两个动作。偏好快照纳入原确认哈希，新增评价不会改变已经确认的任务；需要点击应用按钮再重新确认。当前没有将偏好设置为所有新任务的默认值。

## 学习与记忆

三个成本特征均越低越好：梁高、受拉纵筋面积、控制利用率。固定归一化为 `x=(h/1000, As/1000, u/1)`，不按当前候选池重新缩放，不裁剪超过1的特征。三权重初始均为1/3，成本评分为 `w·x`。

选择A优于B后，令 `delta=xB-xA`，计算 `p=sigmoid(w·delta/0.25)`，更新 `w←max(0,w+0.25*(1-p)*delta/0.25)`，再归一化为和1。属于最简单的在线成对logistic排序更新，非负权重可达到零；不训练基础大模型。

`outputs/preferences/real.json` 与 `simulated.json`保存固定归一化版本、模型版本、权重和每次评价的候选快照及更新前后权重。可通过 `ENGIAGENT_PREFERENCE_DIR`改变目录。原子替换避免半写入，版本检查拒绝过期页面写入；重新启动进程直接加载，无需重新训练。来源、版本和归一化不兼容时报告错误，不静默混合或重置。

**云端部署提醒：当前仅面向本地单写入者。多用户/多进程需要完善身份隔离、并发控制、持久卷和备份，届时应升级存储；本次不引入数据库。**

## 真正指导搜索的位置

`CandidateSearch.observe`仅接收本次搜索已经通过的方案。初始探索仍按原规则；有已通过方案后，按冻结权重评分选择锚点，生成其梁宽/高、直径和根数邻域，修改现有候选队列的取出优先级。自由尺寸、直径目录和固定输入仍受原约束。

每四个有偏好锚点的后续决策保留一次原规则队列探索。其余按已验算锚点评分优先探索邻域。新候选没有控制利用率，也不估计该值；轨迹中的`anchor_score`和`verified_anchor_features`明确属于已通过父方案。新候选实际执行原设计工具和全部Evaluation后，才会成为可用锚点。

结果JSON中的 `design_search.selection_trace`记录实际选中的参数、最少根数、选择方式、锚点修订及其真实评分。引导关闭时原搜索规则不变；开启时保留相同预算上限，固定截面也可继续探索而不因已取得展示数量提前终止。最终原候选筛选规则仍保留，偏好面板独立报告评分，不把最终重排冒充搜索引导。

## 演示与验证

运行 `python examples/preference_demo.py`，输出位于 `outputs/preference_demo_v1/`；可用`--output-dir`选择独立演示目录。模拟档案跨次保留，因此重复运行会从已有版本继续学习。

首次空档案演示：同一RC梁任务，规则初始搜索提供5个不同通过候选；20次模拟成对评价后，权重从 `(0.3333,0.3333,0.3333)` 变为 `(0.1360,0,0.8640)`，版本20。

|指标|关闭引导|开启引导|
|---|---:|---:|
|实际候选验算|12|12|
|通过次数/不同通过方案|5/5|6/6|
|最低偏好成本评分|0.593346|0.497198|

两组前3轮均为250×500/4Φ20→250×550/3Φ20→250×550/4Φ20。第5轮关闭组尝试250×500/5Φ20，开启组尝试250×550/5Φ20，证明后续计算路径改变。原规则探索仍出现于轨迹中。

额外隔离验证：同一引导算法使用等权初值与学得权重，路径也不同，例如第8轮分别尝试250×550/3Φ20与300×550/3Φ22。由此区分学习权重的影响与单纯切换搜索器的影响。

专项测试验证权重更新、非负归一化、文件来源隔离、过期版本拒绝、独立Python进程重载、重载后实际搜索路径变化、父方案必须先验算、引导结果与全新已有梁独立验算一致，以及原页面评价、模拟、图表和对照交互。

## 文献关系及局限

参考仓库中的 Melchiorre等（2026），《AI-driven human-in-the-loop structural optimization of gridshells》，主要借鉴“将设计者反馈纳入搜索”的思想。论文对象为网壳，并使用图像特征、降维、聚类及NSGA-III等；本实现不复现这些算法，也不把该文方法误称为本文的简单成对学习算法。

当前三维线性偏好只描述局部取舍，不能表示复杂交互、总体安全概率或总造价。模拟20票重复使用少量候选，不是20个独立工程案例；本次改善不证明泛化效果。固定归一化尺度是公开程序选择，可在未来独立研究中检验，但不能加载不同尺度的历史档案直接混训。

散点图只绘制已通过候选，非支配集在上述三维特征中判断，二维投影不一定保持支配关系。这是已搜索可行集的非支配子集，不是全局Pareto前沿。失败尝试仍保留在完整JSON与验算计数中。
