## 1. 新取得的 GB 55008-2021 官方正文

来源公告：https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2021/art_17339_762454.html

通过该公告 HTML 的官方附件下载接口取得 `GB55008-2021_mohurd.pdf`，3,986,824 bytes、26 页。直接下载 URL 存在 `GB55008-2021_mohurd.source.txt`。附件从前言开始，无封面；身份由官方公告与附件名称建立，不凭本地文件名推断。正文物理页 = 印刷页 + 3。文件是扫描图，文本提取不适用；本记录均据页图核对。

- **2.0.2，物理 p5 / 印刷 p2**：50 年设计工作年限下普通 RC 构件混凝土不低于 C25；重复荷载构件不低于 C30；抗震等级不低于二级者不低于 C30；采用 500 MPa 及以上钢筋者不低于 C30。工作年限超过 50 年还应提高。当前简支非抗震梁若使用 HRB500，也不能选 C25。
- **2.0.4，p5–6 / 印刷 p2–3**：混凝土强度设计值从标准值除材料分项系数，混凝土系数不小于 1.4；普通钢筋系数不小于 1.1。具体钢筋还受表 3.2.1 约束。
- **表 3.2.1，p10 / 印刷 p7**：300 MPa 光圆、400 MPa 热轧、500 MPa 热轧的最小材料分项系数分别 1.10、1.10、1.15。不要把 HRB500 也除 1.1。实际设计强度仍按 GB/T50010 已确认材料表选取，不自行替换成未经舍入的商。
- **2.0.8，p6 / 印刷 p3**：允许开裂构件按构件类别和环境类别限制受力裂缝宽度，确保工作年限内承载、使用及耐久性能。
- **2.0.10，p6–7 / 印刷 p3–4**：保护层满足协同、耐久与防火要求，且不小于普通钢筋公称直径、不小于 15 mm。需正确区分最外层钢筋与纵向钢筋各自到表面的距离。
- **4.4.5，p15 / 印刷 p12**：受拉钢筋锚固按钢筋直径、强度、混凝土、外形、端部及抗震等级确定，长度不小于 200 mm。
- **4.4.6、表 4.4.6，p15–16 / 印刷 p12–13**：普通受弯构件受拉钢筋最小配筋率为百分数 `max(0.20, 45*ft/fy)%`，即无量纲 `max(0.002, 0.45*ft/fy)`。梁不能套用部分板构件的 0.15% 特例。矩形梁计算面积按配套设计标准取 bh，不能用 bh0 替代。

GB55008 表中梁最小配筋率数值与旧表恰好一致，但现在的强制性来源须改记 4.4.6；此前“缺少强制性来源”的缺口已由本附件补齐。

## 2. 裂缝：GB50010-2010（2015版）7.1

本地正文：`docs/结构规范/GB_50010-2010(2015版)_混凝土结构设计规范.pdf`。视觉证据 `crack-103.png` 至 `crack-106.png`。

以下适用普通、非预应力、矩形受弯梁，三级裂缝控制；长度 mm，力 N，弯矩 N·mm，应力 MPa。荷载采用准永久组合，不能使用承载力组合。

**7.1.1，p103 / 印刷 p88**：RC 最大裂缝宽度使用准永久组合并考虑长期作用效应。

**7.1.2，p104–106 / 印刷 p89–91**：

```text
w_max = alpha_cr * psi * (sigma_s / Es) * (1.9*cs + 0.08*deq/rho_te)
psi_raw = 1.1 - 0.65*ftk/(rho_te*sigma_s)
psi = clamp(psi_raw, 0.2, 1.0)
deq = sum(ni*di^2) / sum(ni*vi*di)
Ate = 0.5*b*h                    # 矩形受弯梁
rho_te_raw = As/Ate
rho_te_crack = max(rho_te_raw, 0.01)
cs = clamp(纵向受拉钢筋外缘到梁受拉底边的距离, 20, 65)
alpha_cr = 1.9                   # RC 受弯，表7.1.2-1
vi = 1.0                        # 普通带肋钢筋；光圆0.7
```

同直径普通带肋纵筋的 deq = d。保护层若输入的是箍筋外缘保护层，则 cs = cover + stirrup_diameter，经 20–65 mm 限制；cs 不是有效高度扣减量，也不是纵筋中心距离。直接承受重复荷载时 psi=1；环氧涂层带肋筋粘结系数另有 80% 调整，当前普通钢筋范围不套用。

**7.1.4-3，p106 / 印刷 p91**：

```text
sigma_sq = Mq / (0.87*h0*As)
```

其中 Mq 为准永久弯矩。w_max 与按环境及控制等级确认的 w_lim 比较；7.1.2 的表达式已包含长期影响，不再额外乘长期挠度系数。零荷载时不能计算含 1/sigma_s 的式子；应显式返回零荷载边界结果。

重要区别：7.1.2 对 rho_te<0.01 的提升明确限定“在最大裂缝宽度计算中”。挠度计算引用 psi 时，应保留原始 rho_te，不能未经说明把裂缝专用下限传播到刚度计算。

## 3. 开裂短期刚度与长期挠度：7.2

视觉证据 `deflection-112.png` 至 `deflection-115.png`。

**7.2.1，p112 / 印刷 p97**：等截面构件同号弯矩区段可采用该段最大弯矩处刚度。全跨均布荷载简支等截面梁可以用跨中控制刚度作等刚度结构力学计算。

**7.2.2，p112–113 / 印刷 p97–98**：

```text
准永久组合：B = Bs/theta
标准组合：  B = Mk/(Mq*(theta-1)+Mk)*Bs
```

**7.2.3-1，p113 / 印刷 p98**：普通 RC 受弯构件短期刚度：

```text
Bs = Es*As*h0^2 / (1.15*psi + 0.2 + 6*alpha_E*rho/(1+3.5*gamma_f_prime))
alpha_E = Es/Ec
rho = As/(b*h0)
gamma_f_prime = 0           # 矩形，无受压翼缘
```

psi 按 7.1.2 确定，RC 梁使用准永久组合应力；上式 rho 与裂缝 rho_te 不是同一个量。输出 Bs、B 单位 N·mm²。

**7.2.5，p115 / 印刷 p100**：rho'=As'/(b*h0)，rho=As/(b*h0)；rho'=0 时 theta=2.0，rho'=rho 时 theta=1.6，中间线性内插。当前仅单层受拉配筋、未输入受压配筋时使用 theta=2.0，不假设架立筋参与减少长期效应。

对于限定的简支等截面全跨均布荷载，结构力学关系：

```text
q_q = Gk + psi_q*Qk         # kN/m 数值等于 N/mm；自重约定需先处理
Mq = q_q*L^2/8             # L 用 mm -> N·mm
f_long = 5*q_q*L^4/(384*B) # mm
```

不能使用毛截面 Ec*Ig 乘一个 2 就宣称实现规范长期挠度；需要上述配筋、开裂和长期刚度链。GB50010 表3.4.3 的限值与项目使用功能仍须另外确认。

## 4. 适用范围与待实现边界

以上记录只覆盖普通 RC 简支矩形受弯梁的选定材料底线、最小纵筋、裂缝与挠度。预应力、受压筋贡献、重复/动力荷载、非矩形翼缘、轴力、抗震构造、施工与耐久完整审核不从这些简化公式自动推导。零荷载、非正输入、钢筋失效应力、模型范围越界均须显式处理，不能因数值可算而输出完整合规。

## 5. 补充构造视觉核验

### 单层纵筋与架立筋

- 9.2.1，GB50010 正文物理 p130–131 / 印刷 p115–116：支座范围内至少 2 根纵向受力筋；h≥300 mm 时纵筋直径不小于10 mm，h<300 时不小于8 mm；下部水平净距不小于 max(25 mm,dmax)，上部水平净距不小于 max(30 mm,1.5dmax)。这里是净距，不能直接作为中心距。
- 9.2.6，p132–133 / 印刷 p117–118：架立筋直径，跨度<4 m 时不宜小于8 mm，4–6 m 时不宜小于10 mm，>6 m 时不宜小于12 mm；原文是“不宜”，规则强度须如实记录。若按简支计算但实际部分约束，则支座上部构造筋面积不小于跨中下部受力筋计算面积的1/4、不少于2根，自支座边缘向跨内伸出不小于计算跨度1/5。这需要实际支座约束输入。

### 腰筋

- 9.2.13，p137 / 印刷 p122：hw≥450 mm 时两侧沿高度配置纵向构造筋；每侧面积不小于0.001*b*hw，且**不包括上下受力筋和架立筋**；间距不宜大于200 mm。梁宽较大可适当放松的措辞不能据此自动放松，需要明确工程依据。
- hw 转引6.3.1，p70 / 印刷 p55：**矩形截面 hw=h0**；T形为有效高度减翼缘高度，I形为腹板净高。不能直接以总梁高h判定450门槛。

### 一般受拉直锚

2024 修订附件 p12–14 / 印刷 p9–11 覆盖8.3.1，2015正文 p119 / 印刷 p104 给出8.3.2修正：

```text
lab = alpha * fy / ft * d
alpha = 0.14      # 普通带肋；光圆0.16且末端180°弯钩，不纳入纯直锚实现
la = max(zeta_a * lab, 200)
```

ft 在混凝土高于C60时按C60取。ζa 修正：带肋直径>25 mm取1.10；环氧涂层取1.25；施工易受扰动取1.10；多项连乘。实配钢筋多于计算量、较厚保护层等折减均有条件，首轮可以明确不采用这些折减。2024 把组合修正系数下限0.6从“不应”改为“不宜”。

当锚固钢筋保护层≤5d，8.3.1还要求锚固范围内横向构造筋直径≥d/4，对梁柱斜撑间距≤5d，且≤100 mm；因此只有la长度数字不能代表锚固全部满足。

**适用关系待明确：**9.2.2，p131 / 印刷p116，对简支梁下筋从支座边缘算起伸入支座的长度有专门条款：V≤0.7*ft*b*h0时≥5d；较大时带肋≥12d、光圆≥15d，另含砌体支承、集中荷载等细项。应区分此端部伸入长度与一般充分利用受拉强度的la，不可默默混用。若实现限定为一般充分受拉直锚核查，应在报告明确该假设，并同时考虑GB55008 4.4.5的200 mm底线，避免把它宣称为所有支座类型的唯一详图规则。

### 箍筋补充

9.2.9，p134 / 印刷p119：h>800 mm箍筋直径不宜小于8 mm，h≤800不宜小于6 mm。表9.2.9按高剪力(V>0.7ftbh0) / 低剪力分列最大间距：150<h≤300为150/200；300<h≤500为200/300；500<h≤800为250/350；h>800为300/400 mm。高剪力条件下rho_sv=Asv/(b*s)还不得小于0.24*ft/fyv。表格最大间距原文用“宜符合”；不要遗漏几何与最低配箍率的分别判定。

## 6. cn_tools.py 针对性公式复核

2026-10-25 读取当前实现后的结论，未修改代码：

- 6.3.1（p69–70 / 印刷54–55）：r=hw/b≤4系数0.25；r≥6系数0.20；4<r<6线性插值。因此`.25-(r-4)*.025`正确。beta_c在C≤50取1，C80取0.8，其间线性。当前材料限C25–C50，省略beta_c乘1无数值错误。r>6被拒绝是项目范围限制，规范本身有公式。矩形hw=h0是规范定义，不是“conservatively use”假设。
- 6.3.4（p71–72 / 印刷56–57）：一般均布荷载普通梁 Vcs=0.7*ft*b*h0+fyv*(Asv/s)*h0；当前公式正确。fyv按4.2.3取值，受剪时超过360 MPa按360，2024修订p9 / 印刷6已视觉确认。
- 表3.4.3（p26 / 印刷11）：L<7000 mm取L/200；7000≤L≤9000取L/250；L>9000取L/300。括号内更严格值250/300/400用于挠度有较高要求构件。当前代码7000、9000边界正确。
- 8.2.1（p117 / 印刷102）：50年、一类环境梁柱杆最外层钢筋保护层20 mm；混凝土等级不大于C25时增加5 mm。纵向受力筋自身保护层还必须≥其直径。当前c指箍筋外缘保护层、c+箍径比较纵筋直径的几何处理正确；结论受“一类、50年”范围限制。
- 7.2.3（p113–114 / 印刷98–99）未见将普通RC的Bs截断到EcIg的明文。0.85EcI0及未开裂/允许开裂分支属于预应力构件。不能不加来源地给普通RC移植该分支或称EcIg上限为该条要求。
- 当前shear_values/shear_check在低剪力时仍把0.24*ft/fyv作为最低配箍率并据此判失败，这比9.2.9.3要求严格。若保留，必须标注项目保守接受标准；独立验算宜区分规范要求与项目规则。h≤150仍套用表格第一行也属项目保守规则，该表第一行实际为150<h≤300。

### 实施后的处理

上述针对性检查记录的是当时开发版本。现已修改：仅V>0.7ftbh0时应用0.24ft/fyv最低配箍率；低剪力不按该比率判失败。h≤150保留配置箍筋与第一档间距的保守项目策略，并在任务规范中标注。架立筋建议值、侧筋间距和箍筋间距的“不宜/宜”效力也在接受假定中保留。

端部未混用特殊短伸入和一般充分受拉锚固：当前实现明确选用后者的保守直锚方案，并检查支座内可容纳长度及锚固区横向钢筋间距；9.2.2其他端部细节不声称已经覆盖。GB55008正文已另存到docs/结构规范，来源和哈希见任务规范。
