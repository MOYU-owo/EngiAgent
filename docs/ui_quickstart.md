# EngiAgent 网页工作台使用说明

工作台在现有中国规范内核上提供可视化交互；原CLI命令保持可用。

## 启动

```powershell
cd E:\code\Engiagent
conda activate engiagent
python -m pip install -e ".[ui]"
python -m streamlit run streamlit_app.py --server.port 8511
```

本机本轮已安装Streamlit 1.66.1及Graphviz 0.21。安装命令用于其他环境首次准备。浏览器打开 http://127.0.0.1:8511 。默认仅绑定本机，不自动上传至云端，不启用使用统计。

## 先运行一个例子

1. 左侧选择“设计工作台”，执行模式先保持“离线 · 确定性角色”。
2. 展开“需求与案例”，选择“完整新方案设计”，点击“加载案例”。这一步不运行计算。
3. 检查几何、材料、荷载、配筋、构造五组参数；右侧“完整参数确认表”可查看原值、标准化值、单位、来源及确认状态。
4. 模板已经过类型与缺项校验，可点击“确认参数”，再点击“运行任务”。修改任一参数后应先点击“校验参数”，再确认和运行。
5. 查看二维示意、分项结论和关键结果，下载Markdown计算书、完整工程JSON及额外的UI调用审计JSON。

模板预计获得下部3Φ20、跨内双肢Φ8@350、锚固区@100。页面数值读取真实计算输出；不是预置展示数字。宽支座与充分直锚假定应结合确认表理解，不作实际节点详图使用。

## 真实DeepSeek与自然语言

在侧栏切换“DeepSeek · 真实模型”；继续使用现有.env中的DEEPSEEK_API_KEY，网页不要求输入或显示密钥。

在“任务来源”选择“自然语言需求”，可勾选显式案例模板，再输入：

> 按中国规范新设计一根梁，跨度6m，梁宽300mm，梁高550mm，恒载10kN/m不含自重，活载5kN/m，其余采用指定模板。

点击“调用Dispatcher提取参数”才调用模型。模型提取值与模板来源分别列出；检查并确认后，点击运行，才调用Design/Evaluation。离线模式不发起自然语言模型请求。

切换页面、展开详情、选择DAG节点及下载文件，不发起新模型调用。模式改变也需要重新校验与确认，避免把离线确认默认为真实模型执行授权。执行过程中请等待完成；若运行被中断，系统保留错误状态，不会自动重试为通过。

## 局部重算

选择“已有梁独立验算”或“梁高修改与局部重算”，先确认并运行基准。在几何表中把梁高从550改为600；编辑立即撤销运行资格。

点击校验→确认→运行。到“Agent与动态规划”的“工程依赖DAG”查看修订2：材料复用，自重/内力及相关检查重算。在“方案修订比较”中比较真实参数、方案和结论。

仅抗弯模板直接提供100kN·m设计弯矩，DAG中不会把受剪、裂缝、挠度或荷载分析画成已执行。

## 有限改设

选择“挠度超限后有限改设”模板：自动改设已开启，最多3轮。首轮3Φ20挠度不通过，第二轮4Φ20通过；每轮都有独立记录。

选择“改设达到上限停止”模板：在该候选及轮次范围内裂缝仍不通过，页面明确显示失败与停止原因。实际已有梁不允许自动改动原配筋。

## 页面说明

- **设计工作台**：任务来源、参数编辑与确认、真实执行、二维工程示意和结果摘要。编辑尚未校验时，示意使用上一次校验的值，当前草稿不会显示成已通过。
- **计算与规范复核**：实际值、需求/承载/限值、失败原因、LaTeX公式、实际输入、规范依据及原始工具JSON。这里区分工具执行完成、分项通过、请求完成和完整工程审查。
- **Agent与动态规划**：真实角色调用及输入输出、工程DAG与节点检查器、方案修订比较。图与节点选择器配合使用；Graphviz图中没有伪装的点击回传。
- **对照实验**：显示未执行，仅预留接口与统一协议，无虚构指标。

## 状态与限制

“请求项目通过”仅表示此次请求且已实现的检查通过；原型的完整工程审查仍为incomplete。旧结果在草稿修改后标为历史快照，不会代表当前输入。

会话仅保存在当前Streamlit连接内存中。浏览器完全刷新、服务重启或源码热更新后可能需要重新加载/校验任务；这不是跨进程持久化。支持下载报告和JSON，但没有包装成“恢复任务”功能。

没有OCR、三维建模、数据库或正式批量实验。当前图不推测腰筋坐标、节点细节、未给的尺寸/配筋/荷载。Agent耗时只显示适配层实际记录的调用耗时；没有记录的token、费用、工具耗时不显示数字。

设计依据见 [UI设计说明](ui_design_spec.md)，实际验证见 [验收记录](ui_acceptance.md)。
