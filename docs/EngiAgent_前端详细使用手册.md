# EngiAgent 前端详细使用手册

> 2026-11-02功能更新：自然语言模板勾选默认关闭；新设计默认开启有限改设；支持确认直径目录内多候选比较和选用，计算复核及计算书新增公式与数值代入步骤。新版地址8517，详细操作及原失败案例修正见[反馈交付说明](feedback_design_delivery.md)。

版本：2026-11-02，适用于当前仅 CN 规范的工作台。

这份手册按当前页面及按钮编写。第一次使用建议先完成第 3 节的离线设计，再做第 6 节的梁高修改，最后体验专家咨询和真实模型。

## 1. 打开工作台

当前本机地址：<http://127.0.0.1:8512>。

如果打不开，在项目目录打开终端，依次执行：

```powershell
cd E:\code\Engiagent
conda activate engiagent
python -m streamlit run streamlit_app.py --server.port 8512 --server.address 127.0.0.1
```

服务运行期间保留这个终端。若提示端口已占用，先访问上述地址，确认是否已有服务；不必重复启动。换用其他端口启动时，浏览器地址也要相应修改。

仅首次准备环境时需要安装网页依赖：

```powershell
python -m pip install -e ".[ui]"
```

建议使用桌面浏览器并最大化窗口。表格过宽时可横向滚动，部分设置藏在可展开区域里。

## 2. 先认识页面和执行模式

### 2.1 左侧五个工作区

|工作区|主要用途|何时使用|
|---|---|---|
|设计工作台|加载任务、编辑参数、确认并运行、看梁示意和结果|所有计算的起点|
|计算与规范复核|看每项的实际数值、公式、依据、输入和不通过原因|计算结束后核查结果|
|Agent 与动态规划|看角色调用、工具依赖、缓存、修改前后比较|解释系统如何完成计算|
|专家咨询|解释当前结果，提出明确的参数修改|已有计算结果之后|
|对照实验|运行同内核的全量／按目标／缓存对照|研究与汇报时查看机制证据|

顶部会显示当前任务、修订号及处理状态。它们帮助你分辨当前看到的是哪一轮参数和结果。

### 2.2 在“运行设置”选择执行模式

左侧展开 **运行设置**，可以看到三种模式。

|模式|是否调用真实模型|建议用途|
|---|---|---|
|离线 · 确定性角色|不调用；工程计算照常执行|第一次学习、演示、检查公式和参数|
|DeepSeek · 真实模型|自然语言提取、设计／验算计划、专家咨询使用模型|展示完整角色调用过程|
|DeepSeek · 仅需求与咨询|模型理解需求与咨询；设计／验算由程序直接规划|日常结合自然语言使用|

三种模式都使用同一套 CN 工程工具。离线计算也会执行真实公式。离线专家咨询使用有限规则，自由表达的理解能力弱于 DeepSeek。

真实模式使用项目本机 `.env` 中已有的 DeepSeek 配置，网页没有密钥输入框。未配置密钥时，先选离线模式。

**先选模式，再加载、确认和运行。** 中途切换执行模式会撤销当前草稿的确认状态。此后要重新校验、确认、运行，才能继续针对当前结果咨询。

### 2.3 最核心的操作顺序

**加载任务 → 编辑参数 → 校验参数 → 核对采用值 → 确认参数 → 运行任务 → 复核与下载。**

模板加载后若已经校验完整，可以直接确认。只要改过参数，就重新走“校验 → 确认 → 运行”。

## 3. 第一次操作：跑通完整新方案设计

### 第一步：选择离线模式

左侧展开“运行设置”，选择 **离线 · 确定性角色**。

### 第二步：加载模板

进入 **设计工作台**，展开 **需求与案例 · 加载或解析任务**：

1. “任务来源”选 **现有案例模板**。
2. “案例模板”选 **完整新方案设计**。
3. 点击 **加载案例**。

加载只建立任务，不执行工程计算。重新加载案例会重置当前任务、咨询及界面历史；需要保留的结果应先下载。

### 第三步：检查参数

在 **参数与确认** 中，依次查看“几何、材料、荷载、配筋、构造”。本模板的主要条件是：

|项目|模板采用值|
|---|---|
|计算跨度|6000 mm|
|梁截面|300 × 550 mm|
|混凝土／纵筋|C30／HRB400|
|下部纵筋直径|20 mm，根数由设计确定|
|箍筋|HRB400、双肢、直径 8 mm，跨内间距由设计确定|
|输入恒载／活载|10／5 kN/m|
|自重约定|输入恒载不含自重，程序另计|
|裂缝限值|0.3 mm|
|挠度限值|L/250；表中“挠度限值分母”填 250|

这些只是主要条件，完整确认还包括支座、锚固、架立筋、腰筋、活载系数等。模板的宽支座及充分直锚是演示条件，换成自己的任务时应逐项核对。

### 第四步：确认并运行

1. 展开 **确认前核对 · 全部采用值、来源与假定**，检查原输入、计算采用值、来源和单位。
2. 如果没有修改且无缺项，点击 **确认参数**。
3. 点击 **运行任务**。
4. 等待“任务执行结束”，查看右侧结果。

若你修改了任何值，先点 **校验参数**，通过后再点“确认参数”。编辑表格后按 Enter 或点击其他位置结束单元格编辑，再进行校验。

### 第五步：检查是否跑通

原模板通常得到：

- 下部纵筋 **3Φ20**。
- 跨内双肢 **Φ8@350 mm**，锚固区箍筋间距 **100 mm**。
- 抗弯、抗剪、适用构造、裂缝、长期挠度五项通过。
- 抗弯承载力约 **156.907 kN·m**；裂缝约 **0.173 mm**；长期挠度约 **11.714 mm**。

这些数值只用于核对未修改模板。更改参数后应以本次计算为准。梁示意是参数与方案的二维示意，不承担施工图功能。

### 第六步：下载结果

在结果区点击：

|按钮|文件用途|
|---|---|
|下载计算书 .md|阅读中文计算过程、依据及修订记录|
|下载结果 .json|保存完整精度参数、方案、计算结果与轨迹|
|下载调用审计|保存角色调用、执行批次及咨询记录|

建议每个重要版本都保存三份文件，并自行改名，例如“已有梁_550mm_基准”和“已有梁_600mm_修改后”。

## 4. 参数怎么填，按钮为什么会变灰

### 4.1 五组参数分别管什么

|参数组|主要内容|操作提示|
|---|---|---|
|几何|跨度、梁宽、梁高、尺寸上限、保护层、支座宽度|“净保护层”按该字段含义填写；不要直接用有效高度代替梁高|
|材料|混凝土等级、钢筋牌号、容重、骨料、工作年限、安全等级、环境|材料等级通过选项选择；纵筋与箍筋牌号分别核对|
|荷载|恒活载、自重约定、活载系数、设计内力、裂缝与挠度限值|先明确恒载是否已经包含梁自重|
|配筋|纵筋层数、直径和根数、箍筋直径、肢数及间距|新设计隐藏由工具确定的根数、跨内箍筋间距；已有梁需提供实配值|
|构造|端部直锚、锚固区箍筋、架立筋、腰筋|跨内箍筋间距和锚固区间距是两项条件|

材料及结构条件等枚举参数，位于对应分组的“选项 · 结构条件与材料等级”展开框中。数字在表格里编辑。

### 4.2 数值和单位分开填写

- 跨度 6 米：输入值填 `6`，单位填 `m`；或输入 `6000`，单位填 `mm`。
- 恒载 10：输入值填 `10`，单位填 `kN/m`。
- 设计弯矩 100：输入值填 `100`，单位填 `kN·m`。
- 钢筋根数、箍筋肢数、活载系数：填写数字，单位留空。
- 挠度限值 L/250：在网页数值表中填分母 `250`，单位留空。
- 留空表示未提供，`0` 表示明确为零，二者含义不同。

不要把 `600mm` 一起写进数字单元格。单位转换后的实际采用值以确认核对表为准。

### 4.3 三个按钮的关系

|按钮|作用|不可点击时怎么办|
|---|---|---|
|校验参数|检查类型、单位、范围及缺项，形成待确认草稿|先加载一个任务|
|确认参数|批准当前采用值及适用假定|先校验，补齐黄色提示的缺项|
|运行任务|按本次确认的参数执行计算|先确认；修改或切换模式后要重新校验确认|

“确认”不会开始计算，“校验”也不会选筋。必须明确点击“运行任务”。运行结束后按钮再次变灰，是为了防止重复执行同一轮。

### 4.4 自重与直接内力

**恒载不含自重**时，选程序另计自重。梁高变化会改变梁自重，并影响相关内力与检查。

**恒载已含自重**时，选已包含自重，程序不会重复加入。改变截面后，程序也不会擅自改写你确认的输入恒载。

直接设计弯矩主要用于已有梁的局部验算。新设计应从确认荷载计算内力。需要学习直接弯矩输入时，先使用“仅抗弯局部验算”模板，避免同时混用直接内力和荷载。

## 5. 已有梁验算与仅抗弯检查

### 5.1 验算已经确定的梁

1. 模板选 **已有梁独立验算**，点击“加载案例”。
2. 核对实际尺寸、实配钢筋和箍筋。
3. 修改后点“校验参数”，再确认、运行。
4. 在“计算与规范复核”逐项看结果。

该模板为下部 3Φ20、跨内双肢 Φ8@250 mm。它与新设计得到的 @350 mm 可能不同：这里核查的是输入的已有方案，不会自动替换成新设计方案。

### 5.2 只验抗弯

1. 加载 **仅抗弯局部验算**。
2. 检查设计弯矩 100 kN·m、实际截面和实配纵筋。
3. 确认并运行。
4. 在结果和 DAG 中核对本次只进行了目标相关计算。

只验抗弯时，不会由此得到抗剪、构造、裂缝及挠度通过的结论。

已有梁的目标可以在 **任务与验算设置 → 验算目标** 调整；选择后重新校验。新设计固定进行全部五项检查。

## 6. 练习：梁高从 550 改到 600 mm

这是理解局部重算最直观的一次操作。

1. 加载“已有梁独立验算”，确认并运行一次基准。
2. 下载基准结果，暂时不要重新加载案例。
3. 在工作台“几何”表把梁高改成 `600`，单位保持 `mm`。
4. 按 Enter 结束编辑；点击 **校验参数 → 确认参数 → 运行任务**。
5. 在“Agent 与动态规划”打开 **方案修订比较**，选择修改前后两轮。
6. 打开 **工程依赖 DAG**，选择修改后的方案轮次和独立验算阶段。
7. 选择材料、几何、荷载、内力等节点，观察“处理”和“原因”。

原模板为另计自重：材料可复用，梁高相关几何、自重、内力及相关检查会重算。已经包含自重的任务，荷载与内力能否复用取决于实际输入依赖，不应要求所有任务呈现同样的节点颜色。

编辑但未重新计算时，页面会标出待处理草稿；旧结果仍可作为历史查看。编辑尚未校验时，示意图使用上次校验参数，不会马上代表刚输入的数字。

## 7. 练习：有限自动改设

### 7.1 挠度不通过后增加纵筋

加载 **挠度超限后有限改设**，在“任务与验算设置”查看：

- 任务为新方案设计。
- “有限自动改设”开启。
- “最多轮次”为 3。

确认运行后，原模板通常第一轮 3Φ20 的挠度不通过，第二轮 4Φ20 通过。到“方案修订比较”查看两轮真实配筋与验算结论。

目前改设动作范围有限，主要尝试同直径增加纵筋，不等于自由搜索全部尺寸、材料和配筋方案。提供的截面尺寸按固定尺寸处理。

### 7.2 观察未找到通过方案时如何停止

加载 **改设达到上限停止**，确认运行。它收紧了裂缝限值，在设定候选和轮次内仍可能不通过。查看停止原因、最后候选以及每轮记录。

这属于预期工程失败，不是程序一定出了故障。“达到上限”只表示本次搜索停止，不能解释为所有可能方案都无解。

已有梁验算不开放自动改设，以免自动改变实配钢筋。

## 8. 专家咨询：怎么问、怎么采用建议

### 8.1 先有当前工程结果

先在工作台完成一个任务，再进入 **专家咨询**。可问：

> 为什么抗弯通过仍需要检查长期挠度？

> 当前裂缝为什么不通过？

> 哪些工具复用了缓存？

点击 **提交咨询**，查看解释和“查看依据”中的实际计算值、公式及引用。离线咨询按有限规则识别关键词；希望自由提问时，先选择 DeepSeek 模式并完成该模式下的确认、运行。

### 8.2 提出明确参数修改

建议第一次用这个完整例子：

> 梁高改为600mm。

1. 点击“提交咨询”。
2. 在“参数建议 · 尚未计算修改后结果”中核对原值、新值、单位和原文。
3. 点击 **将建议写入待确认草稿**。
4. 返回 **设计工作台**，核对草稿。
5. 点击 **确认参数 → 运行任务**；若又编辑了其他值，先重新校验。
6. 看新结果、修订比较，再下载。

采用建议只会形成草稿，不会立即计算，更不等于修改后通过。

**咨询修改会保留当前实配方案，并转为已有梁验算，保留原验算目标。** 例如原设计已得到 3Φ20，咨询修改梁高后验算的仍是保留下来的配筋。若要重新自动选筋，回到工作台建立新设计任务。

### 8.3 怎样表达更容易成功

|表达|建议|
|---|---|
|梁高改为600mm|适合离线与真实模式的明确赋值|
|活载改为6kN/m|明确字段、新值与单位|
|梁高改为0.6m，活载改为6kN/m|复杂表达优先用 DeepSeek；逐项核对建议|
|活载提高一点|缺少最终数值，需要澄清|
|帮我优化一下|可以讨论方向；不能据此认定已有明确修改或最优方案|

旧咨询绑定原修订。结果更新后，旧建议可能标为“历史依据，不能采用”；已采用的建议不能重复使用。已有未完成草稿时，也不能继续采用另一条修改建议。

## 9. 真实自然语言建立任务

1. 左侧“运行设置”选择 **DeepSeek · 仅需求与咨询**，或“DeepSeek · 真实模型”。
2. 工作台“任务来源”选 **自然语言需求**。
3. “案例模板”选“完整新方案设计”。
4. 本次练习主动勾选 **采用上述显式参数模板**。
5. 输入下列需求，点击 **调用 Dispatcher 提取参数**：

> 按中国规范新设计一根简支矩形梁，跨度6m，梁宽300mm，梁高550mm，恒载10kN/m不含自重，活载5kN/m，其余采用指定模板。

6. 查看确认核对表，区分“模型提取”和“显式案例模板”的来源。
7. 校对所有工程条件，再确认、运行。

模板中的材料、构造等参数是你选择沿用的条件，不是模型从这一句话推断出来的。取消模板后，需要提供更完整的条件，缺项会要求补充。

提取参数后不自动运行。读取详情、切换工作区或下载结果也不会自行发起新模型调用。

## 10. “计算与规范复核”怎么读

先看摘要，再进入抗弯、抗剪、构造、裂缝、长期挠度标签页。

每项通常包括：

1. **工具执行**：函数是否正常完成。
2. **分项结论**：该工程检查是否通过。
3. **计算值与采用条件**：实际数值与限值。
4. **实现公式 · LaTeX**：当前工具采用的公式展示。
5. **规范依据与版本**：该项已记录的规范依据及公式版本。
6. **实际输入参数**：本次工具实际使用的输入。
7. 原始输入输出和哈希：需要追溯时再展开。

“其余实际计算步骤 · 材料、荷载、内力与设计”可以进一步查看材料设计值、组合和内力来源。

|显示状态|正确读法|
|---|---|
|执行完成|工具返回正常；仍要看分项结论|
|请求项目通过|本轮请求且支持的检查通过|
|请求项目不通过|存在工程条件不满足，查看原因并考虑修改|
|执行错误|计算或模型环节异常，未形成有效通过结论|
|上游阻断|所需上游结果无效，本节点没有获得有效计算结果|
|完整工程审查未完成|仍有当前原型未覆盖的工程审查范围|

抗弯和抗剪摘要通常把作用值放在前、承载力放在后；裂缝和挠度把计算值放在前、限值放在后。构造包含多个条件，展开看具体原因。

## 11. “Agent 与动态规划”怎么用

### Agent 执行图

查看实际记录的角色、模式、状态、耗时和结构化输入输出。Dispatcher 负责理解任务，Design/Evaluation 组织工具计划；工程结果来自确定性工具。

离线固定角色、程序规划和真实模型会分别标注。角色记录数量不能直接当作真实网络请求数量。页面没有记录的 token、费用或模型内部思维，不会提供对应数据。

### 工程依赖 DAG

1. 选择 **方案轮次**。
2. 选择 **Evaluation · 独立验算** 或 **Design · 配筋设计**。
3. 在 **选择节点查看详情** 中选择节点。
4. 查看右侧处理方式、原因、公式版本和实际输入输出。

绿色表示已执行，蓝色表示缓存复用，灰色是待执行计划，琥珀表示阻断，红色表示失败；具体分项是否通过还要看检查结论。点击图形本身不承担节点详情切换，请使用节点选择框。

已有梁没有设计阶段是正常的；仅抗弯没有无关的验算节点也是正常的。尚未运行的计划不等于已完成计算。

### 方案修订比较

需要至少两轮实际记录。选择“修改前”和“修改后”，查看变化参数、修改后工具处理与两轮结论。加载全新模板会重置当前会话历史，连续修订时不要重新加载。

## 12. “对照实验”怎么用

页面分为两部分。

### 已实现：工程依赖与缓存机制对照

点击 **运行机制对照实验** 才执行。默认覆盖 20 种目标／修改组合，三个执行组各运行 60 次，共 180 次：

|执行组|含义|
|---|---|
|全量无缓存|每次完整计算五项，不复用缓存|
|按目标无缓存|只运行请求目标相关工具，不复用缓存|
|按目标与有效缓存|只运行相关工具，并复用有效结果|

看“请求项输出一致”是否全部成立，再看实际执行节点、复用量和本机耗时。可下载实验 JSON 和报告。

切换页面不会自动重跑；再次主动点击运行按钮会产生新的一次实验。减少执行节点不保证本机总耗时同比降低。

### 尚未完成：统一案例正式对照

人工设计、通用 LLM、固定 Python、EngiAgent 四组的正式比较仍显示 **未执行**。上面的机制对照不会自动变成这四组的效果验证。

汇报时可以展示机制输出一致性和节点复用，不应据此宣称人机速度优越性、跨任务学习或完整工程准确率。

## 13. 上传文件与保存会话

“上传任务 JSON”适用于任务输入文件，例如项目中的：

- `examples/engineering/cn_design.json`
- `examples/engineering/cn_existing.json`
- `examples/engineering/cn_flexure_only.json`

选择文件后点击 **读取并校验文件**，再检查参数、确认并运行。

**下载的“结果 .json”和“调用审计”不是直接上传恢复用的任务文件。** 它们保存完整执行状态或审计数据；当前前端没有跨进程恢复历史会话功能。

当前任务保存在内存。完全刷新浏览器、断开会话或重启服务可能丢失界面状态。重要结果及时下载；切换左侧工作区通常保留当前会话，不要通过刷新来代替页面导航。

## 14. 常见问题

|问题|处理方式|
|---|---|
|看不到执行模式|展开左侧“运行设置”|
|运行按钮灰色|按顺序校验、确认；修改或切换模式会撤销确认|
|确认按钮灰色|检查五组中的缺项，结束单元格编辑后重新校验|
|改了数值，图没变|先校验；未校验时仍显示旧参数；新结果须运行后生成|
|自然语言提取按钮灰色|切换 DeepSeek，填写非空需求|
|DeepSeek 配置或网络报错|检查本机配置和网络；想先验证计算就用离线模板|
|专家咨询按钮不可用|先完成当前任务，确保没有待处理草稿，并输入问题|
|咨询建议采用按钮灰色|可能已经采用、依据陈旧或有未完成草稿；针对最新结果重新咨询|
|为什么修改后还有旧结果|旧结果被保留供历史复核；看页面修订号和“尚未重新运行”提示|
|仅抗弯没有挠度结果|本轮没有请求该检查；需要时增加目标并补齐参数再运行|
|达到上限还是不通过|在本次候选与轮次内未找到通过方案；看失败项并重新明确设计条件|
|完整工程审查一直未完成|这是当前系统的覆盖范围说明，不是单项通过状态|
|只看到一轮，无法比较|先运行基准，再在同一任务中修改并重新运行|
|上传下载的结果文件失败|上传应为任务输入 JSON；完整结果和审计不直接恢复为任务|

## 15. 一次 8 分钟的学习／汇报演示

1. **完整设计**：离线加载“完整新方案设计”，确认、运行，展示 3Φ20 和五项结果。
2. **公式复核**：进入“计算与规范复核”，展示裂缝、长期挠度的数值和依据。
3. **修改与缓存**：加载已有梁并完成基准，把梁高 550 改为 600，校验、确认、运行；展示修订比较及材料复用。
4. **专家咨询**：问“为什么抗弯通过仍需要检查长期挠度”，再提出一个明确修改，展示建议及确认流程。
5. **有限改设**：用“挠度超限后有限改设”展示 3Φ20 到 4Φ20 的实际轮次。
6. **机制实验**：主动运行机制对照，展示请求输出一致和实际节点复用。

先按上述顺序自己完整操作一次。演示时重点说清“输入是什么、哪些已确认、工具算了什么、结果属于哪一轮”。

## 16. 当前适用范围

前端仅运行 CN 规范相关功能，支持当前实现的简支矩形 RC 梁、全跨均布恒活载、单层受拉筋及相应检查。不是通用结构分析或完整施工设计软件。

当前不支持把框架、悬臂、集中荷载、预应力、抗震专项等任务直接套入此模型；没有 OCR、完整三维建模、跨进程会话恢复或跨任务学习。端部节点、现场构造和完整工程审查仍需单独处理。
