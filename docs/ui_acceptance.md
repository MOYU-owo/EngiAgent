## 环境与启动

实际环境：Python 3.11，D:/anaconda/envs/engiagent；Streamlit 1.66.1，Graphviz Python包0.21。前端仅新增ui可选依赖；无React工程、Next.js、数据库或额外后端服务。

```powershell
cd E:\code\Engiagent
conda activate engiagent
python -m pip install -e ".[ui]"
python -m streamlit run streamlit_app.py --server.port 8511
```

本轮服务实际启动并验证于 http://127.0.0.1:8511 ，仅绑定本机。后续服务停止时使用上述命令重新启动。

实际执行：`python scripts/run_tests.py`。

**131 passed in 12.20s**。日志：`outputs/ui/pytest.txt`。包括此前110项业务回归、14项UI适配/投影测试、7项Streamlit AppTest。

六类案例均经适配层实际运行，与保存的原始工程JSON结果逐项对照；Streamlit页面测试覆盖五类直接案例以及梁高修改的第六类交互。用于对照的已执行快照摘要保存在tests/data/ui_reference.json，注明原路径及SHA256，不依赖被git忽略的outputs目录才能运行测试。这是界面一致性回归数据，不替代已有独立工程算术基准。

使用本机内置浏览器操作最终工作台，不通过隐藏会话状态注入结果。检查1366×900与1920×1080视口，截图分辨率已使用图像读取工具核实。

- 实际加载完整设计案例，点击确认和运行，得到3Φ20以及五项检查通过。页面显示Mu需求116.381kN·m、容量156.907kN·m、裂缝约0.173mm、长期挠度约11.714mm，与原记录一致。
- 检查公式区实际KaTeX渲染：当时DOM中有21个已渲染数学节点、0个katex-error。未将普通文本公式截图冒充LaTeX排版。
- 检查Agent结构化事件、手动确认后的新请求边与DAG缓存节点。手动新请求没有被画成自动失败反馈。
- 使用网页显式切换DeepSeek模式，选择仅抗弯模板并输入“按中国规范对已有梁只验算抗弯，设计弯矩100kN·m，实配3根直径20mm的HRB400纵筋，其余采用指定模板”。真实Dispatcher完成解析；在确认表核对模型提取的根数、直径、弯矩及模板尺寸后人工确认，真实Evaluation返回工具计划并运行确定性工具。页面实际显示100kN·m需求、156.907kN·m容量、请求项目通过，完整审查仍为未完成。本次仅调用Dispatcher和Evaluation，不把未发生的Design调用补进图中。

## 已知限制与未完成的人工回执

1. 内置浏览器的自动下载回执等待未完成，随后浏览器连接中断；没有取得本轮网页下载的JSON文件。因此不宣称“浏览器文件落盘”验收成功。下载按钮由Streamlit提供，导出字节与工程JSON/Markdown一致性已通过程序测试；用户可在正常浏览器手动点击下载。
2. Graphviz图以邻接节点选择器进行检查，不支持直接点击图中节点回传选择。图自带放大/全屏；1366px复杂子图可使用全屏查看。
3. 会话是当前连接内存，不是持久化任务队列。浏览器完全刷新、服务重启可能丢失状态；开发源码热更新需重新校验确认。热更新旧Python类实例失配在适配层重建并撤销确认，未改工程计算内核。
4. 不存在OCR、三维节点详图、跨进程恢复、正式批量实验、模型内部思维、未记录的token/费用或逐工具耗时。不存在的功能没有包装成可用按钮。
5. 构造检查有多项条件，没有单个“承载力”数值；该行数值列为空值，详情逐项给出，不能读成0或检查缺失。完整工程审查仍为incomplete，节点、现场构造与超出支持范围的工作不由本原型代替。
