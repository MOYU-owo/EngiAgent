# 工程工具：仅 CN

更新：2026-11-02。旧教学计算工具、承载力折减系数、圆柱强度输入和毛截面弹性挠度分支已移除。本项目只运行 `cn-2024`。

当前唯一工具注册表位于 `src/engi_agent/engineering/cn_tools.py`，输入由 `CNParameters` 校验；输出由 `cn_outputs.py` 校验，并记录实际依据及公式版本。

- [当前公式、工具与规范映射](rc_beam_cn_design_spec.md)
- [条文与公式原文复核](rc_beam_cn_formula_review.md)
- [独立算术参考案例](cn_reference_case.md)
- [依赖声明与执行结构](architecture.md)

材料采用已实现的中国规范等级及设计值。恒活载按 CN 组合；裂缝及长期挠度采用已实现的准永久组合及刚度公式。单位错误、未知字段、非有限数值、缺失关键条件或未确认参数均不能开始计算。

工程不通过、工具异常和上游阻断分别记录，执行成功不等于验算通过。完整适用边界和未覆盖项以当前任务规范和报告为准。
