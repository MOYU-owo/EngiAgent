# 本地规范原文

此目录的PDF为本地资料输入，不随Git提交。工程程序运行不读取PDF；已核实的参数、公式及适用边界见上级目录的 `rc_beam_cn_design_spec.md` 与 `rc_beam_cn_formula_review.md`。

本地审查使用：

- GB 50010-2010（2015年版）正文，配合2024年局部修订；修订后名称及编号为《混凝土结构设计标准》GB/T 50010-2010。
- GB 55001-2021《工程结构通用规范》。
- GB 55008-2021《混凝土结构通用规范》。
- GB 50009-2012《建筑结构荷载规范》。

2024年修订发布依据：[住建部公告](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2024/art_17339_778180.html)。GB 55008的原始公开来源：[住建部公告及附件](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2021/art_17339_762454.html)。

注意：本地文件“混凝土结构设计标准.pdf”仅为40页的2024年局部修订，不能当作完整标准。
