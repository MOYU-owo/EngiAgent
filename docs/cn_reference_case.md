# 中国规范参考案例与独立算术基准

日期：2026-10-25。参考输入为 `examples/engineering/cn_design.json`。

这不是论文OCR数值复刻，而是使用已核验公式、常见公制参数建立的独立基准。以下算术先按力学和条文代入，再与工程工具比对；测试中的正常使用链另用m、N、Pa计算，以检查单位边界。

## 输入及假定

L=6000mm，b=300mm，h=550mm，保护层c=30mm；下部3Φ20，双肢Φ8箍筋。C30：fc=14.3、ft=1.43、ftk=2.01MPa，Ec=30000MPa；HRB400：fy=fyv=360MPa，Es=200000MPa。

外加Gk=10kN/m、不含自重，Qk=5kN/m，容重25kN/m³，ψq=0.5。支座宽1000mm。本示例特意采用宽支座，以容纳声明的800mm充分受拉直锚；不是通用300mm支座节点详图。一般端部伸入/弯锚另需按相应节点设计。

上部2Φ12，每侧腰筋2Φ12，最大竖向间距180mm；锚固区箍筋100mm。50年、二级、一类环境、非抗震专项。裂缝限值0.3mm、用户挠度限值L/250。构造与使用功能假定见任务规范。

## 裂缝与长期挠度

ρte=942.477796/(0.5×300×550)=0.0114239733，大于裂缝计算专用下限0.01。

σs=74.8125×10⁶/(0.87×502×942.477796)=181.752365MPa。

ψ=1.1−0.65×2.01/(0.0114239733×181.752365)=0.470766024；cs=30+8=38mm，deq=20mm。

wmax=1.9×0.470766024×181.752365/200000×(1.9×38+0.08×20/0.0114239733)=**0.172531929mm**，小于0.3mm。

ρ=942.477796/(300×502)。Bs=EsAs h0²/(1.15ψ+0.2+6(Es/Ec)ρ)=**4.78988584×10¹³N·mm²**。

忽略受压钢筋有利作用，θ=2，B=Bs/2=**2.39494292×10¹³N·mm²**。

f=5×16.625×6000⁴/(384B)=**11.7141362mm**；用户限值6000/250=24mm，通过。

将限值改成L/600（10mm）时初始3Φ20失败，允许有限改设后4Φ20通过。这是改设回归案例。将裂缝限值收紧至0.01mm，则在固定尺寸与最多3轮的候选范围内不能通过，系统必须停止并报告。

## 构造关键数值

下部3Φ20净距=(300−2×(30+8)−3×20)/2=82mm；最小采用max(25,20,4×20/3)=26.6667mm。

保守充分受拉直锚需求=max(0.14×360/1.43×20,200)=704.895105mm；提供800mm，并且800≤1000−30。锚固区间距100≤min(5×20,100)。

hw=h0=502≥450，每侧腰筋需求0.001×300×502=150.6mm²；每侧2Φ12面积226.194671mm²，满足本模型检查。原文“不宜”类建议作为项目接受准则，在报告中保留说明。
