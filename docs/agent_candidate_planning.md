# Design Agent 的下一轮改参决策

在运行设置中选择「DeepSeek · 真实模型」，正常确认并运行新设计任务。勾选的直径目录、固定尺寸与自由尺寸范围仍有效。初次方案按原计算工具产生；每轮独立验算后，若需要继续设计，由真实DeepSeek直接决定下一组梁宽、梁高、纵筋直径、最少根数及理由，也可以说明停止原因。

「离线 · 确定性角色」和「DeepSeek · 仅需求与咨询」继续使用规则搜索，便于对照。偏好面板的同预算对照仍比较两种程序搜索，不是LLM规划对照。

模型收到本轮真实验算输出、失败原因、已尝试参数与结果、剩余尝试次数、尺寸边界及允许直径。若任务启用偏好，模型从第一次失败后的决策开始就能读取冻结的偏好权重；不再要求本任务先有通过方案。

模型输出不包含工程验算结论，最少根数也不是最终配筋根数。原设计工具确定实际配筋，所有候选仍执行工程DAG和Evaluation。程序拒绝修改固定尺寸、越界或不符合步长的自由尺寸、未授权直径、重复参数组合及无效结构化输出；调用失败或决策被拒绝时明确停止，不静默改由规则作决定。预算与已取得足够合格候选等原有停止条件仍有效。

查看结果中的方案修订原因（以「Design Agent：」开头）与调用审计中的`DesignDecision`。完整JSON的`design_search.decision_mode`区分`llm`和`rule`；`selection_trace`保存模型提议、接受/拒绝/停止状态、理由及实际执行参数。文字理由是模型的解释，可能存在工程理解偏差，不能替代计算结果。

本次真实调用记录位于`outputs/agent_candidate_planning/live_summary.json`及`live_result.json`。默认模板初始Φ14得到5Φ14并因构造不通过；模型真实提出改用允许的Φ20，工具重算为3Φ20，独立验算全部通过。此单案例证明决策接口实际生效，不证明其优于规则搜索或已学会工程师偏好。

未加入案例记忆检索、基础模型训练、自动修改其他构造输入或新Agent。新接口增加了模型调用成本，并可能提出无效或效果不佳的候选，需要后续同预算实验评价。
