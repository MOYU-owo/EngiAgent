# 后续对照实验记录模板

本轮交付实验准备，不把尚未实施的人工或通用模型实验填成已有结果。

## 统一条件

四组对象：人工工程设计、无本项目专用工具的通用LLM、同一中国规范工具的固定Python流程、EngiAgent。

统一规范版本、构件范围、输入、目标、停止条件与输出要求。允许合理的不同计算顺序。LLM组明确是否允许计算器；若允许，另设分组，不能与完全无工具结果混淆。模型、温度、日期、提示、工具权限、调用次数与重试均保留。

任务至少包含：完整设计、已有梁验算、直接内力局部抗弯、缺失荷载、修改梁高（另计及已含自重两种）、配筋不足、裂缝/挠度超限、约束内改设未通过。以独立复核而非本项目自身输出作为最终真值。

## 每次运行记录

|字段|填写内容|
|---|---|
|任务ID/输入版本|固定案例与哈希|
|执行组/人员或模型|版本与运行配置|
|规范与目标|条文版本及请求检查|
|材料与荷载假定|新增假定及是否被确认|
|输出方案|截面、配筋、构造、各分项结果|
|复核差异|数值误差、漏项、错用公式或组合|
|执行过程|步骤数、重复计算数、无关工具数|
|修改一致性|局部重算与全量计算是否一致|
|交互与成本|人工介入次数、耗时、调用数、token及费用（可得时填写）|
|停止与异常|未通过、不支持、缺项、模型或工具错误|
|证据位置|原始提示、响应、报告、JSON及人工计算书|

固定程序与EngiAgent必须使用相同规范计算内核；该消融用于区分确定性工具、目标解析和动态编排带来的作用。分别报告数值正确性、任务完成、遗漏识别、修改后状态一致性，不能仅用答案误差证明多智能体整体优势。
