用户要求“最简单完成，不要复杂，尽量跑通多的阶段”。保留三个角色、中文命令行与原 Demo，优先跑通中国规范计算、按需规划、参数修改后的局部重算及有限改设。

构件范围：普通非预应力、非抗震专项的单跨简支矩形 RC 梁，全跨均布恒载和活载，单层受拉钢筋。检查目标包括受弯、受剪、适用构造、裂缝和规范挠度。超出范围返回明确说明。

## 1. 规范和计算基线

- 编写 `docs/rc_beam_cn_design_spec.md`，以规范—任务—工具映射表、必要流程图和计算说明为主。
- 配套读取 GB 50010-2010（2015 年版）正文与 2024 修订文件，并结合 GB 55001、GB 50009、GB 55008；确认版本与覆盖关系。
- 仅提取相关页；每条规则记录条号、物理页、印刷页、公式版本、单位、适用条件和核验状态。
- 用常见整数参数建立参考案例，独立计算关键结果；测试真值不能直接取自产出的工程工具。
- 明确材料等级、荷载代表值、安全等级、设计工作年限、环境条件、支承和锚固等必要输入。能否声明完成取决于已覆盖的检查，未覆盖项必须显式列出。

验收：计算项目均有依据；经验初选与规范要求分开；资料缺口不能以默认数值掩盖。

## 2. 中国规范设计与独立验算

- 保留原教学模式和 Demo；增加可辨识的中国规范计算配置，防止两套参数混用。
- 增加材料等级及规范参数查询，适配作用组合、受弯、受剪和适用构造检查。
- 新增裂缝及考虑长期作用的规范挠度计算，不以毛截面弹性挠度替代。
- Evaluation 从实际截面、实配钢筋及荷载重新验算，不读取 Design 的通过结论作为依据。
- 延续参数确认、过程表格、Markdown 报告与 JSON 轨迹。缺项、超范围、计算失败和工具异常必须分别报告。

验收：完整设计、已有梁完整验算、仅抗弯验算可运行；与独立基准一致；不足配筋、超限及异常案例不能输出通过。

## 3. 最小可用 DAG 与局部重算

- 用简单依赖表定义工具、直接输入字段、前置结果、输出及版本，无需引入复杂图框架。
- 按目标求依赖闭包与执行顺序；已给设计内力时，校验其性质后允许跳过荷载和内力计算。
- 按实际依赖输入、规范配置及工具版本判断缓存有效性。设计与验算结果不能错误互代。
- 在当前进程内支持修改梁高、荷载或配筋，重新确认后计算受影响的节点。
- 自重由系统计算、已含自重以及直接提供内力的情况使用不同依赖规则。
- 记录执行、复用、失效、跳过和阻断原因；工具失败仅阻断真实依赖的后续节点。

验收：完整设计、局部验算及梁高变更三类轨迹可解释；局部重算结果与全量重算一致；无关节点不执行。

## 4. 有限次数改设

- 单轮计算保持 DAG；LangGraph 在外层组织失败诊断、方案修订及重新验算。
- 在明确的截面与配筋候选范围内进行简单搜索，遵守固定尺寸等用户约束。
- 每轮创建方案修订并记录修改原因，不覆盖历史方案。
- 根据实际配筋重算有效高度与验算结果；次数上限、无可行方案或超范围时正常停止。
- 初期采用易复核的规则和确定性候选选择，不让模型任意改写计算结论。

验收：至少一个初始失败后改设通过案例，以及一个约束内无解案例；循环次数有界、历史可追溯。

## 5. 演示与交付

- 提供自然语言和离线 JSON 示例，采用常见整数参数。
- 提供完整设计、已有梁验算、局部验算、参数修改、改设成功及无解示例。
- 报告包含输入、依据、设计/验算结果、方案修订、工具轨迹和未完成事项。
- 完成离线回归后，进行少量真实 DeepSeek 调用；分别记录实际验证情况。
- 提供简短运行指南，以及人工、通用 LLM、固定 Python 流程与 EngiAgent 的对照记录模板。未实际完成的实验不填写虚构结果。

最终演示链：自然语言输入 → 参数确认 → 中国规范设计 → 独立验算 → 必要时有限改设 → 参数修改与局部重算 → 中文报告。
