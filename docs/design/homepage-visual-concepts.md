## 首页论点

1. 这是钢筋混凝土梁的设计与验算工具 → 大幅、可辨认的梁与配筋对象。
2. 每个结论有计算过程 → 展示真实公式、参数与复核入口，不编造通过率或认证。
3. 可以开始处理一根梁 → 首屏直接进入按钮，下滑进入参数确认区域。

页面核心句：项目中同一根梁，从首页的材料剖切展品，变成计算页中可编辑的工程对象。

技能抽取：初始 product-performs，seed 1799478677。该方向要求真实可操作产品片段，本次仅输出概念图，改用以工程实体为主体的 hero-object，seed 937289887；保留既有冷灰与海军蓝品牌和中文无衬线字体。三个图是这一工程对象主题的视觉探索，不作为已通过网页检查的实现。

## A：暗场混凝土剖切

首屏：近黑海军蓝、白色大字、长梁斜贯画面、局部混凝土剖切露出钢筋笼。

标题：让每一根梁 / 都有据可循

说明：面向中国规范的钢筋混凝土梁设计、验算与咨询。

按钮：进入计算工作台

动效提案：先呈现实体梁，滚动时切换到配筋状态，再将梁的视角收束至工作台工程视图。文字按行短距离入场，仅一次；进入按钮始终可用。

可交互项：实体／配筋切换。初期可用同视角两张图片交叉淡化；鼠标悬停不作为唯一触发方式。

优势：第一印象最强。成本：静帧＋轻动效为中；连续三维镜头与准确配筋模型为高。

## B：白底结构展品

首屏：冷白底、海军蓝字、大片留给灰色梁与钢筋剖切展品，下面是示例参数和三种视图切换。

标题：看见结构 / 算清依据

说明：钢筋混凝土简支梁，从参数确认到计算复核。

按钮：进入计算工作台

示例输入：跨度 6.0 m；截面 300 × 550 mm；C30 / HRB400。必须标示为示例，不标成当前用户任务，也不伪造验算结果。

动效提案：实体／配筋／截面同视角切换。下滑时展示对象缩小到工程视图区，参数区接续出现，避免翻屏黑白突变。

优势：最易与现有工作台形成同一产品体验，适合长期使用。成本：中。

## C：计算书巨幅排版

首屏：白底巨幅中文标题，下方整块海军蓝舞台，左侧真实基础内力公式，右侧混凝土梁截面展品。

标题：把设计，算明白。

说明：中国规范下的钢筋混凝土梁设计与独立验算。

按钮：进入计算工作台

公式：M = qL² / 8。仅作为全跨均布荷载简支梁的内力关系展示，不替代内核，也不表示给定参数已经通过规范验算。

动效提案：滚动揭示荷载、内力、配筋、复核四个内容片段；公式最终用 LaTeX 原生排版而非图片，保留可读性。

可交互项：选择当前查看的计算环节；使用仓库真实示例或说明性静态内容，未接入计算前不展示动态数值结果。

优势：学术与工程表达更直接，移动端易适配。成本：低至中。

## 推荐落地方式

优先 A 的材料主视觉，采用 B 的浅色工作台接续方式。首页长度控制在约一至两屏，主按钮可直接跳过展示。

先用精修静帧与少量透明度／位移动效验证效果，再决定是否需要 WebGL。固定素材只表达默认示例，用户修改参数后的工程图须由实际任务数据驱动。

移动端单独裁切，保留完整标题、说明和按钮；展示图降为半屏，取消长时间固定滚动。减少动态效果设置下显示静帧，所有入口保持可操作。

本轮不实施网页，不声称浏览器检查、响应式检查或性能测量已完成。生成图为视觉提案，钢筋细部和中文文本在实施时需按实际数据与原生排版重建。
