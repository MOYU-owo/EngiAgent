# 首页平面配筋图与梁模型联动概念

2026-11-03。根据用户新想法，在第三轮认可的纸白画板基础上，探索一张左右并置的首页静态概念图。

## 构图

- 页头和底部中文标题、说明沿用第三轮。
- 中间仍是连续完整的画板，不拆成两张卡片。
- 左侧约六成：一层梁配筋施工平面图，采用正投影视角、轴网、柱截面、主次梁和必要尺寸配筋标注，避免画成带家具的建筑平面。
- 右侧约四成：同一根选中梁的细腻混凝土与钢筋剖切模型。
- 以梁编号 L7 与简洁引出线连接两者。局部低饱和蓝色仅表示实际选中的梁。
- 图中十字光标与捕捉方框表示鼠标悬停时的 CAD 状态。

## 拟议交互

鼠标在平面图移动时显示局部十字光标；悬停一根梁后描亮该梁，右侧展示对应梁的模型和编号。点击可锁定选择，触屏使用点选，减少动态效果时保持可选的静态视图。

这是交互方向，不是本轮已经实现的网页功能。本轮只生成一张静态图。

平面图与标注属于视觉示例，不作为施工图或已验证的分析数据。后续若落地，应以真实构件数据驱动平面图、选择与模型。现有内核支持范围仍为已实现的单梁设计与验算，首页呈现楼层平面不等于已实现整层结构分析。
